> **SCMP（服务合作管理系统）** 是一套面向 IT 基础设施、智能化弱电及弱电工程施工外包领域的双向协同管理平台。系统覆盖内部立项预算硬上限管控、资质准入拦截派单、在途调价变更、施工分批完工验收、违约核减扣款、服务商合并开大票报销以及对接公司外部财务报销系统（ERP）打款的全流程闭环。

## 🛡️ 核心业务决策规则与状态机设计 (v2.0.0 规范)

1. **强制双选与资质拦截原则（派单时点有效原则）**：
   - PM 在发起派单时，服务商与具体施工工程师均为必选；
   - 系统内置动态资质引擎：根据项目配置的准入证书门槛（支持 `AND` 全部持有 / `OR` 满足其一），严格过滤且仅允许选择**派单时点证书未过期且已通过内部核验**的合格人员；
   - 派单成功后自动生成当前持证快照（编号、发证日、到期日），永久留痕备查。
2. **项目委外预算硬上限红线（不可突破规则）**：
   - 单项目派单累计金额严禁超出立项总预算；
   - 无论初始派单还是在途追加工单金额，均受剩余可用预算硬约束；若需调增必须走正式项目立项追加扩容流程。
3. **长工期项目分批完工与严格串行控制规则**：
   - 工程师支持根据现场施工进度分批（如 30%、60%、100%）提报完工成果与对应申报金额；
   - **串行控制防刷机制**：前一笔完工批次审核通过后，方可提报下一批完工；
   - 现场**客户已签字盖章的验收确认单原件**为内部验收合格的终审必备证据。
4. **完工终审直接核减扣款与锁额规则（B1 方案）**：
   - 若服务商工期延误或质量瑕疵，审核人员直接在完工验收环节录入扣款金额与扣减原因（如延期违约金）；
   - 终审判定额直接锁定进入服务商待报销池，结算报销阶段不再二次扣减，权责清晰。
5. **服务商接口人合并开大票报销规则（A1 方案）**：
   - 报销由服务商接口负责人集中发起，可跨项目勾选旗下多笔已完工批次合并报销；
   - **允许开具 1 张总金额相符的增值税专用发票**，无需每一小笔工单单独开票，极大降低税费成本与财务沟通负担。
6. **外部财务报销系统推单与 Webhook 打款闭环**：
   - 内部管理初审发票与对公账户无误后，一键推单至公司外部财务系统（ERP）；
   - 外部财务打款完成后，通过 Webhook 异步回调通知本系统（包含银行流水号与打款时间），工单批次全流程归档结清。

## 📱 PC 端与手机移动端全响应式设计

系统基于 **Tailwind CSS + PostCSS** 构建了统一的多端适配规范，无需针对不同设备开发多套前端代码：

| 交互场景 | PC 宽屏桌面端体验 | 手机 / 平板移动触控端体验 |
| :--- | :--- | :--- |
| **主导航体系** | 常驻深色侧边栏 + 实时待办红点角标统计 | 顶部极简栏 + 侧滑抽屉 (`el-drawer`) + **底部大拇指快捷触控栏** |
| **数据列表展示** | 宽屏多列对比表格，右侧固定快捷操作列 | **响应式卡片流 (`block md:hidden`)**，单手大按钮触控，杜绝表格挤压与横向滚动 |
| **操作对话框** | 居中精致弹窗 (`460px~560px`)，分步引导 | **全宽自适应弹窗 (`w-[92vw]`)**，输入框与选择器大尺寸防误触 |
| **审核对比台** | 左右分屏对照（派单要求 vs 施工成果与签字单） | 纵向折叠卡片对比，签字单支持点击查看高清原图 |

## 🚀 快速启动指南

### 1. 环境准备
- Node.js >= 18.0.0
- npm >= 9.0.0 (Windows 环境下推荐使用 `npm.cmd`)

### 2. 安装依赖并启动本地服务
```bash
# 进入前端工程目录
cd scmp-frontend

# 安装依赖
npm install

# 启动本地开发服务器 (默认端口 5173，自动暴露局域网 IP)
npm run dev
```

启动后在浏览器访问：
- 本机访问：`http://localhost:5173`
- 手机端真机调试：同一局域网下手机浏览器输入终端提示的 Network IP（例如 `http://192.168.x.x:5173`）。

### 3. 一键切换 5 大模拟角色体验全流程
在界面右上方或移动端菜单中，点击头像可随时秒级切换角色体验差异：
1. **张经理 (项目经理 PM)**：选项目查预算余量、资质拦截派单、在途调价与主动撤回；
2. **李主管 (审核管理人员)**：审核派单、完工验收直接核减扣款、报销初审并推送到外部 ERP；
3. **系统管理员**：合作企业对公账户安全变更、工程师上传证书真实性审核；
4. **周建国 (服务商接口负责人)**：管理团队证书到期续期、跨项目勾选多笔完工批次合并开大票报销；
5. **陈明 (现场履约工程师)**：手机端查收工单任务、一键确认接单、分批提报完工与上传签字单。

### 4. 生产构建打包与类型检查
```bash
# 运行 TypeScript 类型静态检查与 Vite 生产打包
npm run build
```
打包输出目录为 `scmp-frontend/dist/`。
